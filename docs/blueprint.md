# **App Name**: Clipperly

## Core Features:

- Home Page: Home page with a brief intro, call-to-action buttons and service highlights.
- About Page: About page with barbershop story.
- Barbers & Testimonials: Barbers and Testimonials pages to display staff and client comments.
- Gallery Page: A page showing off the stylebook and latest cuts
- Contact Info: Contact page with email and social media contact information.
- Testimonial Generator: AI tool generates a sample testimonial.

## Style Guidelines:

- Primary color: charcoal black (#1c1c1e), evoking vintage barbershop vibes but in a modern, sophisticated way.
- Background color: ivory white (#f9f9f6), same hue as the primary color but much lighter and desaturated for a calm background.
- Accent color: gold (#ffd700), provides contrast and a touch of elegance.
- Headline font: 'Playfair', a modern serif for a high-end feel.
- Body font: 'PT Sans', a humanist sans-serif for body text, to be paired with Playfair for headlines.
- Use clean, vector-based icons related to barber services (scissors, razor, comb).
- Responsive grid layout with smooth transitions and animations.
- Subtle animations on hover states for buttons and images, parallax scrolling effects on the homepage.
